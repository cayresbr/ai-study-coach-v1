AI Study Coach

Cole o link de uma aula ou de uma playlist do YouTube. O app monta a grade curricular, guarda seu progresso e gera um quiz de 10 questões cobrindo tudo o que você já estudou — sem backend e sem chave de API.

1. Cole o link do curso

Aceita youtube.com/playlist?list=…, youtube.com/watch?v=…&list=…, youtu.be/… ou apenas o ID da playlist.

Sobre o projeto e o roadmap
V1 — Front-end local (esta versão)
HTML, CSS e JavaScript puro. Playlist lida pela IFrame API do YouTube, títulos pelo oEmbed público, progresso em localStorage por curso.
V2 — Backend Node/Express
Rotas, validação, API própria, tratamento de erros e separação cliente/servidor.
V3 — Banco e autenticação
Usuários, progresso persistente, hash de senha e sessões/JWT.
V4 — IA com segurança
Geração de questões conceituais para qualquer playlist, com a chamada à IA feita só pelo backend: rate limiting, validação e proteção de secrets.
